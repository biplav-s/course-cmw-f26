# Exercises related to software development

1. A generic process involves:
   - Customer:
      >- requirements
   - Developer: 
     >- specification
     >- design
     >- development (coding)
     >- testing
     >- release
   - Customer:
     >- evaluation
     >- acceptance
2. The above process is highly simplified and rarely happens in one-round. Read about 'Software Development Life Cycles' (SDLCs).
